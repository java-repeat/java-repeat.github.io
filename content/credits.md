## Contributors

java-repeat is built by [its contributors on GitHub](https://github.com/java-repeat/java-repeat/graphs/contributors). Issues and pull requests are welcome in [java-repeat/java-repeat](https://github.com/java-repeat/java-repeat).

## Inspiration

The API follows Kotlin's [`repeat`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/repeat.html) function: same name, same zero-based index, same no-op for a zero or negative count.
